# temp · 排查临时中转区

排查过程中的中间产物（SLS 输出、主机回传原文、截图草稿、脚本草稿）可先落本目录：案例建 `<案例缩写>-<日期>/` 子目录，内部可临时按 `sls/ · host/ · screenshots/` 归类（结案全部清零）。

**结案必须清零**（只留本 README）：报告（md + 自包含 HTML、辅助佐证报告）与截图归到交付区 `D:\temp\<客服账号名>\`——`证据区\` **只保留 `screenshots\`**，`sls\` / `host\` / `scripts\` 一律不创建；原始 json/日志与一次性脚本不留存，复现命令内嵌报告。规范见 `docs/REPORT_STANDARD.md` §5.1 / §5.2。

本目录内容为工作产物，不入库（见根目录 .gitignore）；无运行时工具读取它，可随时清理。
